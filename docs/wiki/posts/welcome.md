# Welcome to the DyonLaw Wiki

This wiki is the public journal of the **Departement-Of-Dyon** — commentary,
amendments explained, enforcement notices, and notes on the Dyonian Legal Code.

## How it works

- Posts live in this repository as plain Markdown files
- New entries are published through the **Admin** page, which commits them
  directly to GitHub — no build step, no server
- The wiki reads `posts/index.json` for the post list and `posts/<slug>.md`
  for each entry

## Reading the Code

The laws themselves are not here — they live in the applications:

- **DyonLaw for Windows** (v2.0.0) — the full reader
- **DyonLaw Terminal** (v1.0.0) — the console edition

Both are free on the [releases page](https://github.com/Departement-Of-Dyon/dyon-law/releases).
